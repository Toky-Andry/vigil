# Vigil

Plateforme de monitoring de serveurs avec détection d'anomalies.

## Démarrage rapide
1. Copier `.env.example` en `.env` et définir un mot de passe
2. `docker compose --env-file .env -f infra/docker-compose.yml up -d`
3. Base de données disponible sur `localhost:5433`
